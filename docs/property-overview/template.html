About this sample and its limits

This view uses complete historical records from 25 authorised BUILD cases. It is not a live work queue or decision-time replay. Source assertions, evidence gaps and suggested questions remain separate from the property’s present condition.

Rooms are shown only when named by a source. Addresses and property identities are unverified. Demo positions cannot support routing or distance calculations. Some synthetic event dates are after the review date. Supplied PDFs were counted but not re-examined for this overview.

Suggested checks are prepared from the record. No agent is running here, no message is sent and no policy is changed. Live owners, deadlines and operational actions require a connection to the workflow engine.
