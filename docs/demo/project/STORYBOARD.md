# Property Desk demo edit

Concept: follow one fictional maintenance request through two separate checks and a recorded simulated action, keeping the working application visible throughout.

Picture: real browser recording at 1280×800. A 100px forest-green rail beneath it names the current step and keeps the local-demo boundary visible. Final canvas: 1280×900. No reconstructed UI or decorative motion effects. The recorded pointer overlay follows the actual UI actions. Cuts remove waiting; recorded actions remain in causal order. Narration duration drives scene slots.

Design: the app's forest green (#173D32), warm neutral (#F4F2E9) and off-white (#FAFBF8). Locally bundled Inter regular/bold for a concise rail. Native-size UI is the focal element; chapter title is the supporting edge anchor. A plain field prevents a decorative layer competing with small product text.
