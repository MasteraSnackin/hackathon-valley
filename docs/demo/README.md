# Property Desk working-product demo

[Watch or download the 54-second MP4](property-desk-demo.mp4).

The video is committed directly to this repository. Repository access is required while the project remains private.

The recording shows the real local application handling one fictional maintenance request:

| Time | What happens |
| --- | --- |
| 00:00–00:08 | A tenant reports a leaking kitchen tap and receives a saved-request confirmation. |
| 00:08–00:19 | Staff see two unresolved checks: person/property and permitted contact route. Work classification already passes. |
| 00:19–00:25 | Staff verify one source-supported fact; the separate contact-route check remains open. |
| 00:25–00:37 | The second verification allows native local Vercel Workflow to reassess the case and record a simulated quote request. |
| 00:37–00:46 | Plain-English input produces an unsaved, unpublished policy suggestion. |
| 00:46–00:54 | The case shows progress while explicitly stating that the repair is not yet confirmed. |

All names, addresses and directory evidence are fictional. The recording uses [application revision `23cec52`](https://github.com/MasteraSnackin/hackathon-valley/tree/23cec527a5f3848786b85c965b653982f15a9c57), native local Workflow execution and the literal demonstration interpreter available at that revision. Later Claude integration is outside this recording. No live model, real tenant identity, contractor communication or physical repair is claimed. The narration uses a generic synthetic British English voice.
